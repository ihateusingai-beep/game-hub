    歡迎使用學習遊戲 Hub

    從左邊(或者手機嘅上方)揀一個學習範疇,就會喺呢度用 iframe 載入遊戲。

    等你填咗 GAMES 入面嘅 URL 就可以即刻試。

    1. 打開 index.html
    2. 最頂 const GAMES 入面有 8 個範疇
    3. 每個範疇嘅 url 換成你揀好嘅學習網站
    4. 儲存檔案 → 重新載入瀏覽器
